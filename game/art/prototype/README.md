# D1 原创占位素材

此目录是为 Roguelike1 新建的手工 SVG 矢量占位素材：白板人物、三种敌人、墙体、地面、出口和受击粒子。未导入或覆盖用户既有素材，没有第三方图片依赖；不代表最终商业画风已定。

视觉暂用暗炭底色、灰石墙、纸面具与旧金／青绿色识别。角色区别依靠轮廓和颜色；重大攻击还有叉格预告与文字，不能只依靠颜色。

源 SVG 保留；后续美术迭代创建新文件或版本化变体，再在 Sprite2D.Texture 引用，勿在运行时重写素材。`.svg.import` 属于导入设置，纳入 Git；`.godot/` 导入缓存不纳入 Git。

字体通过 `game/ui/theme.tres` 的 SystemFont 引用用户系统字体，没有复制或重新分发系统字体。本机 Heiti SC 已检查关键中文字形；其他平台需测试对应字体。正式发布前应选定可合法随游戏分发的中文字库及许可文件。音效／音乐与正式动画资产尚未制作。
