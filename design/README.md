## 产品主张

单角色回合制地牢肉鸽。玩家在短房间中用位置、少数技能和可控的压力应对危险，在频繁掉落中改造构筑，逐渐把一套勉强维持的办法变成能碾压普通房间的连锁。

题材采用**中文社区抽象文化融合暗黑地牢**。本轮提出的世界是：日常语言变成了地牢中的物理法则，怪物把荒诞规矩当成神圣秩序。玩家真的可以甩锅、拉扯、硬撑、画饼；诙谐来自这些规则在严肃世界里产生的后果。

## 体验节奏

进入房间，看懂主要威胁 → 决定保守处理还是透支爆发 → 一步一响应，触发技能配合 → 看到掉落但不打断战斗 → 清场后比较、替换、降低压力 → 带着改变后的打法进入下一房。

前期的乐趣是“手里这些东西也能解决问题”；中期是“这个新东西让我换一种打法”；成型后是“这次连锁真的清了一片”。精英和首领要求玩家安排位置与爆发时点，但仍承认构筑带来的优势。

核心差异提议是**能借助压力加速成型构筑的爆发，同时自己决定何时收手**。它不能沦为每次施法前必按的增伤按钮，也不能把回合战斗变成角色随机拒绝指令。

## 有依据的方向与尚无依据的效果

- **来源事实与玩家反馈：**原研究的组件独立可用、过渡期、商店和连锁辨识问题，见[机制档案](../research/2026-10-23/mechanism-dossiers.md)。评价编号只是定性案例，不代表市场比例。
- **设计推断：**固定用途的技能加规则改造，可以使频繁掉落更容易比较；压力可为成熟构筑增加额外的自愿风险。
- **待验证假设：**这些规则能够提高决策质量、让玩家愿意重开。目前没有证据可以报告“已经好玩”或“能够提高留存”。

接下来的讨论优先围绕压力的具体代价、构筑例子是否诱人，以及世界表达的方向。数量、数值和引擎选择在这些问题之后收敛。
