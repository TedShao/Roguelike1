# Roguelike1

单角色回合制地牢 Roguelike，当前处于市场研究与产品设计阶段，尚未开发游戏或制作原型。

仓库：[TedShao/Roguelike1](https://github.com/TedShao/Roguelike1)。现有研究与设计文档已纳入 Git；后续文档和开发内容继续版本管理。

## 当前产品方向

- 单角色、一步一响应，敌人采用关键预告。
- 局内自由构筑，以少数技能配合为主，允许形成核心技能；技能主要采用回合冷却。
- 短房间遭遇串联、频繁掉落、清场后统一调整构筑。
- 允许成型构筑碾压普通房间。
- Steam／桌面优先，网页试玩可选；引擎、镜头和画风开放，Godot 优先评估但未锁定。
